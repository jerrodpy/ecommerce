# Test Task: E-commerce Module on Laravel + Vue.js

## Goal

Build a mini e-commerce module using Laravel and Vue.js, including a product catalog, shopping cart, checkout, and basic authentication.

## Features

### Frontend (Vue.js 3)

- Product catalog (name, price, description, image)
- Filtering by price / category
- Cart: add, remove, change quantity
- Checkout: form with user details
- User login and registration

### Backend (Laravel 10+)

- CRUD for products and categories (admin only)
- Order model linked to products with statuses
- API (using Laravel API Resources)
- Middleware for route protection
- Image upload
- Laravel Sanctum for authentication

## Requirements

- Laravel 10+
- Vue.js 3, Vuex
- TailwindCSS (optional)
- Git with clean commit history
- No Voyager, Nova, Filament, etc.
- Clean and readable code

## Bonus Points

- Unit tests (e.g. for one controller)
- Email notification on order placement
- Repository / Service layer pattern
- README.md with setup instructions
- Screenshots or link to a live demo
